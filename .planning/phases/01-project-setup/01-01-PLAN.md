<task type="auto">
  <name>Task 2: Install and configure TypeScript</name>
  <files>tsconfig.json</files>
  <action>
Install TypeScript and related packages:
- Run `npm install -D typescript ts-node @types/node`

Create tsconfig.json with:
- target: "ES2022"
- module: "NodeNext" (ES modules)
- moduleResolution: "NodeNext"
- outDir: "dist"
- rootDir: "src"
- strict: true
- esModuleInterop: true
- skipLibCheck: true
- forceConsistentCasingInFileNames: true
- resolveJsonModule: true
- declaration: true
- declarationMap: true
- sourceMap: true

Use `npx tsc --init` as starting point, then customize.
  </action>
  <verify>Run `npx tsc --version` and `cat tsconfig.json` to verify configuration</verify>
  <done>TypeScript installed, tsconfig.json exists with compilerOptions targeting ES2022, output to dist/, input from src/</done>
</task>
