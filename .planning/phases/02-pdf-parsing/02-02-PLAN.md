## Phase 2 Context

**Goal:** System can extract raw text and structure from BNP PDFs

**Success Criteria:**

1. System can identify transaction table boundaries in parsed text
2. System extracts complete card number from PDF header ("Numéro de carte XXXX")
3. Parser returns structured intermediate format with raw text sections

**Requirements to cover:**

- PARSE-02: Extract transaction table with date, description, amount columns
- PARSE-04: Extract card number from PDF header (not filename)
- ARCH-03: Extensible parser interface (strategy pattern)

**Architecture Notes (from STATE.md):**
**Planned Pattern:** Strategy pattern for bank parsers

- Interface: `BankParser { canParse(pdf): boolean; parse(pdf): Transaction[] }`
- BNP implementation: `BnpParser implements BankParser`

**BNP PDF Structure (from STATE.md):**

- Card number line: "Numéro de carte 5480 28XX XXXX 8204" → extract "8204"
- Transaction table has columns: Date de transaction | Description | Montant en euros
- Foreign transactions show: "-19,00 USD" with exchange rate on following line

**Depends on:** Plan 02-01 (pdf-parse installed, PdfContent types defined)

      - rawTransactions (empty array for now - Phase 3 will parse individual transactions)
      - rawText (the transaction section text for Phase 3 processing)
